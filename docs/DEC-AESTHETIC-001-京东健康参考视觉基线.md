# DEC-AESTHETIC-001：京东健康参考视觉基线

- 状态：已确认
- 确认日期：2026-09-01
- 适用范围：小喜鹊运动伙伴患者端 H5 / 微信小程序主要界面
- 决策来源：用户明确要求“主要 UI 界面请参照京东健康进行设计”

## 视觉方向

专业、亲和、轻量、可行动。以薄荷绿和青绿色为主色，使用极浅灰白页面背景、白色大圆角模块卡、浅色子卡和绿色胶囊按钮。弱化边框和重阴影，主要依靠留白、圆角与浅背景建立层级。

## 参考产品与采用范围

采用京东健康当前公开页面中可验证的设计规律：

1. 首页采用“顶部频道—AI/搜索入口—快捷服务—健康概览—健康目标/任务—内容推荐”的纵向结构。
2. 健康数据以白色大卡承载，指标在浅色子卡中紧凑排列，并提供“健康全览”入口。
3. 运动页面以“今日运动数据、核心指标、主行动按钮、具体项目”组织。
4. 底部使用五栏导航，中间助手入口视觉突出。
5. “我的”优先呈现个人资料、健康档案、设备和数据服务。

本项目不复制京东健康的医生问诊、购药、商城、订单、红包、京豆和现金挑战模块；这些内容与冠心病居家康复的核心任务无关，也可能稀释医疗专业性。

## 页面映射

| 京东健康公开视觉规律 | 小喜鹊患者端转化 |
|---|---|
| AI 小康入口 | 小喜健康助手 |
| 健康概览 | 心率、血氧、步数、BMI / 活动指标 |
| 健康小目标 | 今日康复目标、计划运动、设备同步 |
| 运动中心 | 今日运动数据、康复处方、八段锦与抗阻训练 |
| 五栏底部导航 | 首页 / 锻炼 / 小喜 / 报告 / 我的 |
| 健康档案入口 | 基础信息、指标趋势、康复摘要与医院记录 |

## 组件与布局规范

- 页面背景：`#F5F7F6`
- 品牌主色：`#22C58B`
- 品牌深色：`#119C70`
- 浅绿色背景：`#E7FAF3`
- 主文字：`#202C28`
- 辅助文字：`#74817D`
- 危险提示：保留红色语义，不能只靠颜色表达
- 主卡圆角：28–34rpx；子卡圆角：18–22rpx；胶囊按钮：999rpx
- 主按钮：绿色或绿—黄绿渐变；危险动作不得使用绿色
- 页面密度：首屏优先展示可行动的健康信息，不加入无关营销瀑布流
- 主正文不小于 18rpx；关键数字和主标题使用 28–58rpx

## 明确禁用

1. 不使用京东商城式大红促销首页或高密度商品瀑布流。
2. 不把医疗异常、运动完成或动作识别结果直接绑定现金惩罚。
3. 不用 AI 文案暗示诊断、处方调整或紧急医疗处置能力。
4. 不隐藏数据来源、模拟评分或原型数据属性。
5. 不因视觉改版移除运动前检查、异常阻断、运动后记录与报告闭环。

## 证据边界

- 当前中国区 App Store 可确认版本为 9.5.2，但公开商店截图仍带有“9.0 全新升级”字样，因此只能作为当前商店可见视觉参考，不能宣称是 9.5.2 登录后所有页面的逐页复刻。
- 健康档案、任务和“我的”页面中未公开验证的具体卡片顺序，均按本项目任务优先级统一推导。
- 本项目工作区的京东健康研究截图用于补充运动中心、健康数据和个人中心结构；敏感账户和健康数值不进入原型。
