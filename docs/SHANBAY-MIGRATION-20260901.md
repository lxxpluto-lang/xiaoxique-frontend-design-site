# 扇贝产品逻辑迁移记录（2026-09-01）

## 本次实现

### VIEW-HOME

- 今日状态由 `0/3 项运动` 改为 `0/1 核心任务`；
- 保留一个“开始今日计划”主按钮；
- 显示推荐理由和数据/计划来源；
- “更多运动”明确为非核心选择，不影响今日完成状态；
- 完成核心任务后，主按钮切换为“查看今日报告”。

### VIEW-ASSISTANT

- 将空白聊天入口降为补充提问；
- 增加四个任务卡：今天怎么练、数值怎么了、报告怎么看、计划要调整吗；
- 每项输出统一为：结论、状态、依据、三步行动、来源/医疗边界；
- 主按钮直接衔接今日训练、报告、设备来源或健康档案。

### VIEW-REPORTS

- 拆分为“今日、趋势、计划、记录”四层；
- 今日页展示核心任务、分钟、完成项目和主指标；
- 趋势页明确“数据不足时不预测”，保留来源/同步/缺失数据说明；
- 计划页使用动态周完成度，不承诺确定的减重或康复日期；
- 历史记录保留训练类型、身体反馈和数据来源。

### VIEW-PROFILE

- 增加可检查的阶段目标；
- 日常用户可选择“建立运动习惯”或“支持健康减重”；
- 心脏康复目标由共享演示处方确定，小喜不能修改；
- 目标、运动、设备和医院数据分别标注来源。

### VIEW-GROWTH

- 增加 7/30/60/100 天里程碑；
- 明确中断不扣除已有积分；
- 积分只奖励健康行动和长期坚持；
- 浏览商品、拉新和付费任务不计入健康积分；
- 兑换内容调整为徽章、恢复课程、报告解读和设备指导。

## 明确保留的边界

- 所有数据和积分仍为本地原型；
- 不连接真实医院、设备、支付或物流；
- 不诊断疾病，不调整药物或康复处方；
- 不以体重结果排名，不默认向队友共享健康数据；
- AR 识别结果仍为演示能力，不能用于真实奖励审核。

## 第二轮：打卡与健康同行

- “报告”新增独立“打卡”子页，集中展示自动打卡状态、动态月历、连续天数与 7/30/60/100 天里程碑；
- 完成当天核心运动时自动打卡并奖励 5 积分，同一天不重复记录，停止或未完成不触发；
- 将静态月历升级为本地日期驱动的打卡记录，并兼容旧版 `checkInDate` 与 `streak` 数据；
- 参考扇贝“发现”页的同桌与小组结构，把“健康小队 / 健康搭子”两张入口卡放到知识库最上方，默认收起、点击原位展开；
- 小队支持创建、邀请码加入、成员状态与单日温和提醒；搭子支持 7/30 天周期、双方状态与单日提醒；
- 社交激励不排名、不惩罚断签、不自动解除关系，也不分享体重、心率、康复处方等健康隐私数据；
- 本地原型存储升级到 `schemaVersion: 3`，组队、搭子、提醒和打卡记录均可在刷新后保留。
