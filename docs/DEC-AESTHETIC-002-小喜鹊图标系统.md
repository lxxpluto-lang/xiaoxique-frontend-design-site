# DEC-AESTHETIC-002：小喜鹊患者端图标系统

## 决策

患者端采用“圆润线性主轮廓 + 单处薄荷绿强调”的图标系统。京东健康只作为信息层级和成熟健康应用体验的参考，不复用其红色品牌色、图标造型或服务宫格视觉资产。

## 视觉原则

1. 图标轮廓优先简单、可一眼识别，避免药箱、红十字等过度医疗化符号。
2. 运动使用跑步人物，设备使用手表，评估使用仪表盘，知识使用打开的书，安全使用盾牌。
3. 主轮廓统一为深墨绿 `#155E50`，重点信息使用薄荷绿 `#38C69A`，必要时增加浅薄荷 `#DDF7EE`。
4. 图标放在浅色圆角容器中，不使用京东健康式红色实心服务入口。
5. “喜”字和小喜鹊插画继续承担品牌角色；通用功能图标只承担导航和识别，不代替品牌形象。

## 色彩可维护性

Iconfont 网页支持调整图标颜色。本项目另外保留 `original/` 原始 SVG，并将应用版控制在三个色值内。未来调整品牌主题时，可在网页端重新导出，也可在 SVG 中批量替换色值。

## 验收标准

- 360–430 px 宽屏幕下图标轮廓清晰，不与标题挤压。
- 同一层级图标尺寸一致，入口图标约 18–24 px，底部导航约 19 px。
- 非选中底部导航通过降低透明度表达状态，不另做一套造型。
- 微信小程序与 H5 构建均能加载本地 SVG；若目标设备兼容性不足，再由原始 SVG 批量导出 PNG 兜底。
- 对外发布前复核 Iconfont 作者授权条款并留存凭证。
